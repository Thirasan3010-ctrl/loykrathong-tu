# ลอยกระทงออนไลน์ 🌕 (Static Web 3D)

เกม 3D บนเว็บ สแกน QR แล้วเล่นได้ทันที แต่งตัว แต่งกระทง เดินไปที่สะพาน แล้วลอยกระทงพร้อมคำอธิษฐาน
ทำด้วย HTML + CSS + JavaScript + Three.js ไม่มี Back-end ข้อมูลเก็บใน `localStorage` ของเครื่องผู้เล่น

## ทดลองเล่นในเครื่อง
ดับเบิลคลิก `index.html` ตรงๆ ไม่ได้ เพราะเบราว์เซอร์บล็อก ES Modules บน `file://` ให้รันเซิร์ฟเวอร์ในเครื่องก่อน

```bash
cd "D:\โปรเจคคนโสด\game"
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

ทดสอบบนมือถือในวง Wi-Fi เดียวกัน: เปิด `http://<IP ของคอม>:8000` (ดู IP ด้วยคำสั่ง `ipconfig`)

## การควบคุม
| อุปกรณ์ | เดิน | ลอยกระทง | เมนู | ย้อนกลับ |
|---|---|---|---|---|
| คีย์บอร์ด | WASD / ลูกศร | E หรือ Space | Esc | - |
| จอยสติ๊ก (Xbox/PS) | สติ๊กซ้าย / D-pad | A (กากบาท) | Start | B (วงกลม) |
| มือถือ | จอยบนจอซ้ายล่าง | ปุ่มบนจอ | ปุ่ม ☰ | ปุ่มย้อนกลับ |

ในหน้าเมนู เลื่อนเลือกปุ่มด้วยสติ๊กหรือ D-pad แล้วกด A

## โครงสร้างไฟล์
```
game/
├─ index.html          หน้าเว็บและหน้าจอทั้งหมด
├─ style.css           หน้าตา UI (รองรับมือถือแนวตั้ง)
├─ js/
│  ├─ main.js          ตัวควบคุมหลัก: หน้าจอ, ลูปเกม, กล้อง, ปล่อยกระทง
│  ├─ world.js         ฉากสระ, อาคารทรงโดม, สะพาน 2 จุด, ร้านค้าพร็อพ, ไฟประดับ
│  ├─ character.js     ตัวละคร Chibi แบบ Modular + ท่าเดิน
│  ├─ krathong.js      กระทง + ของตกแต่ง + คำอธิษฐานบอท
│  ├─ textures.js      ลวดลายทั้งหมดวาดด้วย Canvas (ลายช้าง, ผ้าซิ่น, เสื้อ TU ฯลฯ)
│  ├─ controls.js      คีย์บอร์ด / Gamepad API / จอยบนจอ
│  ├─ audio.js         เพลงประกอบ
│  ├─ storage.js       บันทึกข้อมูลใน localStorage
│  └─ loader.js        เตรียมโหลดโมเดล .glb ในเฟสถัดไป
├─ assets/audio/       เพลง .mp3 (แปลงจากไฟล์ .wav ในโฟลเดอร์ audio/)
├─ assets/models/      ที่วางโมเดล .glb ในอนาคต
├─ vendor/three/       Three.js r170 (เก็บไว้ในโปรเจกต์ ไม่พึ่ง CDN)
└─ credits.txt
```

## ปรับแต่งง่ายๆ
- จำนวนกระทงบอท: `main.js` บรรทัด `for (let i = 0; i < 11; i++) spawnFloater(...)`
- จำนวนคนเดินเล่น: `main.js` บรรทัด `for (let i = 0; i < 4; i++)` ในส่วนบอทเดินเล่น
- คำอธิษฐานบอท: `krathong.js` ตัวแปร `BOT_WISHES`
- ชื่อร้านค้า: `world.js` ตัวแปร `stalls`
- ตำแหน่งสะพาน: `world.js` ตัวแปร `BRIDGES`
- สีเสื้อ/กางเกง: `character.js` ตัวแปร `TOP_COLORS`, `BOTTOM_COLORS`

## ขึ้นเว็บฟรี
**Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → ลากโฟลเดอร์ `game` ทั้งโฟลเดอร์ขึ้นไป ได้ลิงก์ `xxx.pages.dev`
**GitHub Pages:** สร้าง repo แล้วอัปโหลดไฟล์ใน `game` ไว้ที่ root → Settings → Pages → Deploy from branch

จากนั้นนำลิงก์ไปทำ QR Code แล้วโพสต์ TikTok ได้เลย

## ข้อควรรู้
- ผู้เล่นแต่ละคนเห็นกระทงของตัวเอง + กระทงบอท (ไม่ได้แชร์ข้ามเครื่อง)
- ห้ามใส่โลโก้หรือตราสัญลักษณ์ของมหาวิทยาลัย และคงข้อความ "ไม่ใช่กิจกรรมทางการ" ไว้ในหน้าแรก
- ก่อนเผยแพร่ ควรตรวจว่าเพลงไม่ซ้ำกับเพลงที่มีลิขสิทธิ์ (เช่น ฮัมทำนองใน Google app หรือค้นใน Musipedia)
